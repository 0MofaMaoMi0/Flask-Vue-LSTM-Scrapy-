Flag assets
===========
Source: flag-icons 7.6.0 (npm package "flag-icons", MIT), flags/4x3/*.svg
Mapped to ISO 3166-1 alpha-3 filenames used by movie-web/public/m9/globe/world.geojson.
Scope: every country in the globe GeoJSON with a valid ISO code (174 files).

Files are referenced by src/lib/globe/countryDisplay.js as /m9/globe/flags/{ISO3}.svg.
Countries without an ISO code in the GeoJSON (N. Cyprus, Somaliland) fall back to an ISO-code chip.
