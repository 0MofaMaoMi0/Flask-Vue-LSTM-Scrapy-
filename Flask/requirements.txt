# =============================================================================
# 项目依赖清单
#   后端: Flask/          爬虫: scrapy/          前端: vue/（用 npm，不在本文件）
#   目标环境: Python 3.11 + 虚拟环境 .venv（本清单即本机实测通过的版本）
#
# 安装步骤:
#   1) pip install -r requirements.txt -i https://pypi.org/simple --extra-index-url https://www.paddlepaddle.org.cn/packages/stable/cpu/
#   2) pip install --no-deps python-alipay-sdk==3.0.4
#
#   第 1 步为何显式指定 -i:
#       本机 pip 默认源是清华镜像（pypi.tuna.tsinghua.edu.cn），实测不可达；
#       若你的网络能正常访问清华源，可去掉 -i 参数。
#   第 1 步为何要加 --extra-index-url:
#       paddlepaddle 2.6.1 未发布到 PyPI，只在 PaddlePaddle 官方源提供。
#   第 2 步为何要 --no-deps:
#       python-alipay-sdk 硬性声明 pyopenssl==19.1.0，而该版本放不到现代
#       cryptography 上（会让 Scrapy/Twisted 的 TLS 直接报错），
#       所以跳过它自带的依赖解析，改用 PyPI 上正常的 pyOpenSSL，单独装本包。
#
# 本清单只包含两类内容:
#   A. 项目源码中真实 import 的第三方包（后端 13 个 + 爬虫 5 个）
#   B. 版本敏感、漂移后会导致旧版 Flask / Paddle 直接报错的间接依赖
#
# 未列出的说明:
#   paddlenlp 2.6.1 自身声明了 fastapi、uvicorn、datasets、visualdl、paddlefsl、
#   paddle2onnx、onnx、typer、rich 等一批包（训练/可视化/模型转换用），
#   pip 安装时会自动带入；本项目只用到其 Bi-LSTM 推理能力，未直接使用这些包，
#   因此不再逐条罗列，避免把整机环境导出当成项目依赖。
# =============================================================================
