# 项目检查

从任务涉及的模块开始，而不是递归读取整个仓库。

1. 先读根目录 `AGENTS.md` 和 `README.md`；确认当前目录就是源码根。
2. 用 `rg --files` 与精确文本搜索定位入口、调用方、配置和测试；跳过 `.venv*`、`node_modules`、`vue/dist`、上传文件、日志、数据集和模型权重，除非它们正是任务对象。
3. 后端检查 `Flask/app.py`、对应 `api/` 蓝图、模型和前端 `src/api/` 调用；爬虫检查 spider、item、pipeline 和数据库连接；模型检查训练/推理脚本、词表和权重路径。
4. 报告已由代码证实的结构、配置来源、调用链、可运行验证和风险。把 README 与代码不一致之处标为待确认，不凭名称推测模块存在。

只读检查不得启动爬虫、训练模型、写入数据库或读取 `.env` 的值。
