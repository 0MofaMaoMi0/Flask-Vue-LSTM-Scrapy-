# 项目调试

先复现或收集报错，再决定修复范围。检查顺序为：启动命令与当前工作目录、依赖锁定、`.env` 是否存在但不读取其中秘密、相关模块导入、接口链路或构建输出。

- 后端使用 `run_backend.bat` 或在 `Flask/` 下执行入口；前端使用 `vue/` 的 `npm run serve`、`npm run build` 或 `npm run lint`。
- Scrapy 依赖必须使用 `.venv-scrapy`；不得在排障时启动真实 spider。模型问题不得通过重新训练来掩盖。
- 使用 `rg` 定位错误符号和调用链；日志只读取与错误时间相关的片段，避免加载大文件。
- 修复应局限于已证实的根因。完成后重跑最小复现，并报告命令、结果、未覆盖的外部依赖和副作用。

遇到数据库写入、第三方支付/短信/OCR、真实抓取、训练或破坏性操作时停止并请求明确授权。
